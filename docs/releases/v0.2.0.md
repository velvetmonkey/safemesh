This release uses the v0.1.0 tag as its compatibility baseline. That tag has no release assets. This release does not publish packages to crates.io, PyPI, or npm.

## Compatibility

The 31 v0.1.0 fixtures and `v010_compat.rs` test current readers on tagged files. `scripts/check-older-decoder.sh` tests the old decoder on 31 small current inputs. These checks do not establish compatibility for every future file or every history size. The EnableWinsFlag Disable form is not canonical and waits on a format ruling. A tag 0x02 EventLog frame has no checksum; check the old file against a separate trusted copy before migration.
