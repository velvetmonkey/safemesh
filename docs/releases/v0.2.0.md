# SafeMesh v0.2.0

This release uses the v0.1.0 tag as its compatibility baseline. That tag has no release assets. This release does not publish packages to crates.io, PyPI, or npm.

## Changes since v0.1.0

- PR #288: Current readers test 25 tagged wire values and six stored files from v0.1.0, and they refuse named malformed inputs (`rust/crates/safemesh-crdt/tests/v010_compat.rs:1`, `rust/crates/safemesh-crdt/tests/fixtures/v0.1.0/README.md:1`).
- PR #289: The fixture reproduction command now fails when a generated file is missing or differs from the retained bytes (`rust/crates/safemesh-crdt/tests/fixtures/v0.1.0/README.md:53`).
- PR #290: Python and WASM log loaders let callers set a record budget (`rust/crates/safemesh-python/src/lib.rs:783`, `rust/crates/safemesh-wasm/src/lib.rs`).
- PR #291: Default log loaders now refuse more than 100,000 records, and explicit unlimited loaders can read larger histories (`rust/crates/safemesh-crdt/src/codec.rs:235`, `rust/crates/safemesh-crdt/src/local.rs:1295`).
- PR #292: CI uses the tagged v0.1.0 decoder on small current files (`scripts/check-older-decoder.sh:1`, `.github/workflows/ci.yml`).
- PR #293: OR-Set Remove writers now sort and deduplicate tokens before they write bytes (`rust/crates/safemesh-crdt/src/wire.rs:254`).
- PR #294: README Cargo commands now start from the clone root by changing to `rust` first (`README.md`).
- PR #295: The migration guide now warns that a tag 0x02 EventLog frame has no checksum, so a migrated value can differ from the original (`docs/src/content/docs/persist-and-restart.md:216`).
- PR #296: The M2 slice reproduction steps now use portable scratch paths (`evidence/m2slice/README.md`).
- PR #297: The docs now name the tested Python string OR-Set surface and distinguish OR-Set Remove tokens from Enable-wins Flag Disable tokens (`README.md:180`, `docs/src/content/docs/persist-and-restart.md`).

## Compatibility

The 31 v0.1.0 fixtures and `v010_compat.rs` test current readers on tagged files. `scripts/check-older-decoder.sh` tests the old decoder on 31 small current inputs. These checks do not establish compatibility for every future file or every history size. The EnableWinsFlag Disable form is not canonical and waits on a format ruling. A tag 0x02 EventLog frame has no checksum; check the old file against a separate trusted copy before migration.
