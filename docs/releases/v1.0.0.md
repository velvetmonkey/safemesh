# SafeMesh v1.0.0

The v0.2.0 and v0.2.1 tags have no GitHub release. The release publish job makes a GitHub release only; it sends no package to crates.io, PyPI, or npm.

## Changes since v0.2.2

- PR #358: The Diagnose History check matches each displayed error against live text.
- PR #359: The release workflow check requires active, ordered toolchain setup lines.
- PR #365: The bindings name the ownership cause for invalid G-Counter records.
- PR #366: The bindings name the causes for collision, delta type, and replica count records.
- PR #363: Bounded since selection lets repair converge under a record limit.
- PR #367: The WASM since batch respects the record budget.
- PR #368: The release workflow checks clean installs from its release assets.
