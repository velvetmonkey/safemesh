# SafeMesh v0.2.1

The v0.2.0 tag is the compatibility baseline. Its release draft job failed, so v0.2.0 has no GitHub release and no release assets. This release does not publish packages to crates.io, PyPI, or npm.

## Changes since v0.2.0

- PR #319: The restart guide names the `StoreExists` refusal for a second persist to an existing store (`docs/src/content/docs/persist-and-restart.md:141`).
- PR #308: The WASM LWW register replica holds a shared Replica core and admits records and merges collision reports through it (`rust/crates/safemesh-wasm/src/lib.rs:1447`).
- PR #323: The TypeScript gold path uses managed handles in place of its former save sites (`docs/design/node-persistence-adapter.md:9`).
- PR #320: A Rust durable store keeps its own writer counter outside the store directory and refuses a store-only rollback that loses an own-writer record (`CLAIMS.md:43`).
- PR #325: The security policy directs users to private vulnerability reporting (`SECURITY.md:15`).
- PR #324: CI checks the Python matrix claims against the workflow (`.github/workflows/ci.yml:30`).
- PR #321: The journal checks its magic bytes before it reads records (`rust/crates/safemesh-crdt/src/journal.rs:17`).
- PR #326: Enable-Wins Flag admission compares Disable tokens as a set and retains the received vector (`rust/crates/safemesh-crdt/src/crdt/enable_wins_flag.rs:15`).
- PR #322: The docs job checks homepage illustrations in a browser (`.github/workflows/docs.yml:116`).
- PR #327: Fieldcheck gives an `unsupported_format` message when a newer SafeMesh wrote the store (`examples/fieldcheck/fieldcheck.py:151`).
- PR #328: The release workflow binds the repository in the draft, verify, and publish steps (`.github/workflows/release.yml:101`, `:133`, `:158`).
- PR #329: The two-app inventory test starts each peer with a separate port (`demos/two-app-inventory/test_sync.py:37`).
- PR #330: A test requires recovery when damaged wrapper magic has a high version digit (`rust/crates/safemesh-crdt/tests/wrapper_version.rs:200`).
- PR #331: Fieldcheck gives a named message when a peer has newer writes for the same writer (`examples/fieldcheck/fieldcheck.py:145`).
- PR #332: The action pin checker finds workflows from its own path, also reads `.yaml` files, accepts quoted `uses` values, and refuses a scan that finds no `uses` line (`scripts/check-action-pins.py:8`, `:32`).
- PR #334: The docs version test reports the exact WASM README line for a wrong version (`scripts/check-doc-versions.test.mjs:84`).
- PR #333: The Python matrix checker compares runner names in the docs with the workflow runner (`scripts/check-python-matrix-claims.mjs:100`).
- PR #335: Package smoke runs the WASM counter width check (`scripts/package-smoke.sh:204`).
- PR #336: The docs job tests its link crawler against a local server (`.github/workflows/docs.yml:99`).
- PR #337: Package smoke requires the WASM checklist journey to report 2006 records (`scripts/package-smoke.sh:223`).
- PR #338: The README names local build commands next to the future package install commands (`README.md:91`).
- PR #339: The current package versions and release checker now name v0.2.1 (`rust/crates/safemesh-crdt/Cargo.toml:6`, `scripts/check-release-workflow.py:54`).
