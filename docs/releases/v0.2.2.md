# SafeMesh v0.2.2

The v0.2.1 tag is the compatibility baseline. Its release build job failed, so v0.2.1 has no GitHub release and no release assets. The changes of v0.2.1 are listed in `docs/releases/v0.2.1.md` and ship first in this release. This release does not publish packages to crates.io, PyPI, or npm.

## Changes since v0.2.1

- PR #340: The asset build includes the core, FFI, Python, and WASM SBOM files (`scripts/build-release-assets.sh:21-26`).
- PR #342: The demo index labels the examples as v0.2 showcase demos (`demos/README.md:6`).
- PR #343: The inventory demo guide adds steps to run the stored record regression in a new virtual environment (`demos/two-app-inventory/README.md:176`).
- PR #344: The inventory demo frames each stored record with SHA-256 and refuses a frame that fails its check (`demos/two-app-inventory/README.md:155-156`).
- PR #345: Nested decode limits check the record count before record admission (`rust/crates/safemesh-crdt/src/codec.rs:951-954`).
- PR #346: The docs job checks Diagnose text against damaged Rust store errors (`.github/workflows/docs.yml:92-93`).
- PR #341: The release asset tool step exports the pinned Rust toolchain before it installs wasm-pack (`.github/workflows/release.yml:74-77`).
- PR #347: The docs job checks claim evidence links (`.github/workflows/docs.yml:100-101`).
- PR #348: The v0.2.1 fixture guide records the tagged source and retained wire bytes (`rust/crates/safemesh-crdt/tests/fixtures/v0.2.1/README.md:3-5`).
- PR #351: The Diagnose checker accepts the displayed error with or without an on restart context (`scripts/check-diagnose-history.py:100-103`).
- PR #349: CI checks the retention budget report and its test cases (`.github/workflows/ci.yml:270-271`).
- PR #352: External wire tests add a custom replica codec (`rust/crates/safemesh-crdt/tests/external_wire.rs:209-220`).
- PR #353: The docs job installs Chromium for the web browser check (`.github/workflows/docs.yml:117`).
- PR #354: CI compares release assets from two checkouts of the same commit (`.github/workflows/ci.yml:45-46`).
- PR #355: A separate packaged Rust consumer checks a crate archive as a path dependency (`examples/packaged-consumer/README.md:3`).
- PR #356: The v0.2.1 compatibility test computes SHA-256 for retained fixture bytes (`rust/crates/safemesh-crdt/tests/v021_compat.rs:321`).
- PR #357: Retention budget tests cover excess time and memory values (`scripts/check-retention-budget.test.py:41-42`).
- PR #360: A test checks that duplicate resends at a permanent gap do not grow the journal (`rust/crates/safemesh-crdt/tests/duplicate_resend_cost.rs:10-11`).
- PR #361: The restart guide states that the older decoder must refuse current fence and transaction files cleanly (`docs/src/content/docs/persist-and-restart.md:502-506`).
- PR #362: The current package versions and packaged Rust consumer path now name v0.2.2 (`rust/crates/safemesh-crdt/Cargo.toml:6`, `examples/packaged-consumer/Cargo.toml:10`).
